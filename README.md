# Intelligent Signal Processing - Course Project
This repository documents my progress through the Intelligent Signal Processing course. It's a work-in-progress collection of assignments, experiments, and notes as I work through the material.

### Purpose
* Track my progress - a personal record of what I've covered and where I'm at in the course.
* Learn in public - if someone else is taking a similar course (or just curious about intelligent signal processing), feel free to follow along, compare notes, or learn alongside me.

### What's inside
- Course assignments and exercises
- Experiments and implementations
- Notes and observations along the way

A note on the code
This is learning material, not production code, so expect rough edges, works-in-progress, and the occasional dead end. That's part of the process.
